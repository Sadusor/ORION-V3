# ORION Product UI

The implementation lives in `ui/strata/`, derived from Claude's STRATA V3 package.

**It is not Remote V2. V1 Remote is frozen and separate.**

Surfaces: Home, Work, AI, Memory, Connectors, System.

Foundation includes PC + phone responsive presentation, Personal / Project / Specialists / Background lanes, five cloud-specialist slots, connector status fabric, and truthful STRATA state/evidence rules.

Backend wiring is a later gate. See `ui/strata/INTEGRATION.md` and `docs/decisions/0015-freeze-v1-build-product-ui-and-connectors.md`.
