# HistoryArchive disposable SQLite migration qualification

Host-side tests open only temporary databases. They create the original V1 chat schema and rows, execute the V2 tombstone migration, close and reopen the database, confirm conversation/message retention, then exercise transactional deletion, tombstone persistence across restart, a simulated replay check and transaction rollback. The tests also execute the onCreate SQL extracted from Android source. This is **real SQLite SQL execution in Python, not Android SQLiteOpenHelper execution or a device test**; the deletion sequence mirrors Android logic and does not certify the Android runtime. No production database, server, app, Update button or TheHands implementation is altered. Next gate after PASS: owner-approved isolated test APK installation and Android device/emulator tests.
